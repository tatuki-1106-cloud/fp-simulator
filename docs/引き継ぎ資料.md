## 1. 現状のサマリ

FP-UNIVライクな日本のライフプラン・シミュレーター。月次キャッシュフロー計算エンジン + FastAPI/Jinja2/HTMXのWeb UI + MCPサーバー(AI連携)を実装済み。Cloud Runにデプロイ済み。

### 実装済み機能

| 分野 | 内容 |
|---|---|
| 計算エンジン | 月次CF、所得税(年末調整モデル)、住民税(翌年6月〜)、社会保険(厚生年金/健保/介護/雇用、都道府県別)、老齢年金(基礎+厚生+繰上/繰下+加給、公的年金等控除による雑所得課税)、退職金(分離課税) |
| 拡張機能 | 住宅ローン(元利/元金均等・繰上返済・ボーナス払い・据置・住宅ローン控除)、教育費(公立/私立パス)、iDeCo/NISA(掛金所得控除・一時金/年金の受取時課税・NISA枠分離/枠復活)、保険、産休育休(Q2入力・日割り給付・キャッシュフロー統合) |
| UI | 2カラムレイアウト(左サイドバーQ1〜Q11)、ライフマップ(タイムライン)、年次CF表、貯蓄残高グラフ(Chart.js)、前提条件表示 |

### 3.5 産休・育休の計算前提

- 設定はQ2の各収入に紐づき、1収入に複数の休業レコードを登録できる。
- 産前産後休業・産後パパ育休・育児休業を別期間で入力する。
- 給与・賞与・給付金は暦日で日割りする。給付金は生活設計用の月次受給相当額として計上し、実際の2か月ごとの振込は再現しない。
- 社会保険料は日割りせず、休業期間が月末を含む月を全額免除する簡略モデル。
- 国民年金・国保区分の収入には、雇用保険・健康保険を前提とする休業給付を計上しない。
- 所得税の社会保険料控除は、休業による当年の免除月を反映した年次推定額を使う。
- 給付金の対象日数、標準報酬月額、給付率、社会保険免除判定は月次明細の計算根拠と公式出典リンクから確認できる。

### 3.6 iDeCo・NISA・公的年金課税の計算前提

- iDeCo掛金は小規模企業共済等掛金控除として所得税・住民税の両方へ年次推定で反映する。加入区分(第1号68,000円/第2号23,000円/第3号23,000円)はQ11フォームで選択でき、拠出限度額の判定に使う(企業年金の有無による細分は簡略化)。
- iDeCo一時金は受取開始年齢の到達月に残高(一時金+年金の場合は指定割合)を退職所得として分離課税する。加入年数は「初期残高分の加入済み年数+シミュレーション中の拠出月数(1年未満切上げ)」。
- 退職所得控除の重複調整(簡易版): 同一メンバーで退職金の後1〜19年内にiDeCo一時金を受け取る場合はiDeCo側、iDeCo一時金の後1〜4年内に退職金を受け取る場合は退職金側の控除年数から、勤続期間とiDeCo加入期間(年齢ベース近似)の重複年数を差し引く。同一年受取の合算計算・暦日単位の判定・控除額ベースの精密調整は行わない。調整時はトレースに「重複調整」を出力する。
- iDeCo年金受取は受取期間(annuity_years、未設定=残高が尽きるまで)を指定でき、受取開始年齢+期間で受取を終了する。
- 受給開始後(一時金受取済み・年金受取開始後)は脱退扱いとなり、以後の掛金拠出を停止する。掛金控除の年次推定も同じ基準で月数を数える。
- iDeCo年金受取と老齢年金はメンバーごとに合算し、公的年金等控除(国税庁No.1600、他所得1,000万円以下の表)を適用した雑所得として総合課税する。年金受取の年間推定は残高不足による減額を考慮しない。給与がなく年間税額0の月は所得税トレースを出力しない。
- 公的年金等雑所得とiDeCo掛金控除の年次推定は`AnnualTaxEstimateCache`で年単位にキャッシュし、月次ループでの再計算を避ける。
- 旧データ移行: receive_typeが既定値「一時金」のまま受取月額が設定されたiDeCoプランは「年金」受取として読み込む(旧UIの月次受取+概算税率モデルの互換)。旧withdrawal_tax_rateフィールドは無視される。
- NISAはつみたて投資枠(年120万円)・成長投資枠(年240万円・生涯1,200万円)を分離管理し、つみたて枠超過分は成長枠へ自動振替する。生涯枠(1,800万円)は簿価ベースで消費し、取崩し時は評価額按分で簿価を減らして翌年1月に枠を復活させる。初期残高は簿価=評価額とみなして生涯枠を消費する(従来は消費しない扱いだった)。

### 5.1 公式モデル・代表世帯ベンチマーク

精度検証用に、次の2層で回帰テストを保持している。

- 公式値: 国税庁の給与所得控除・所得税・住民税の計算例、日本年金機構の老齢基礎年金・厚生年金モデル値
- 代表世帯: 会社員(年収600万円)・専業配偶者・子1人、住宅ローン・車両費・保険・生活費を組み合わせた2025年開始の月次CF

公式値の出典:

- 国税庁「給与所得控除」: https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm
- 日本年金機構「令和7年度の年金額改定」: `parameters/pension.yaml` に出典URLを記録
- 厚生年金・社会保険料率: `parameters/social_insurance.yaml` に出典URLを記録

代表世帯ベンチマークは制度計算の正しさを単独で証明するものではなく、公式値を含む複数機能の連携、月境界、年次集計、残高更新を検知するために使用する。
